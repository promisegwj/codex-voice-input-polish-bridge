隐私与数据使用

本功能仅处理 Codex 语音输入链路中的文本；不会监听键盘、鼠标或普通手动输入，不会采集屏幕操作，也不会将校准记录用于语音输入优化以外的用途。

数据记录条件

仅在启用持续学习，并且你保存语音审核结果或主动校准样本时，写入原始识别文本、自动整理文本、发送给 Codex 的最终文本和整理规则。记录保存在本机，用于生成候选规则。

配置概览

以下设置分别控制自动应用、学习方式、访问方式和手动校准方式。首次使用时可以先启用自动应用，确认效果后再开启持续学习。

持续学习

在你保存语音输入结果时记录文本差异，并在指定时间生成本地候选规则。

访问与启动

固定配置网页地址，并保存是否随 Codex 启动校准服务的偏好。

自动应用

主动校准

通过话题样本测试整理效果，并把你确认后的文本保存为校准样本。

启用自动对比校准

开启后，保存语音审核结果或主动校准样本时，记录“原始识别文本、自动整理文本、发送给 Codex 的最终文本”之间的差异。

每日迭代时间

到达该时间后，本地脚本读取已保存的差异记录并生成候选规则。该设置仅在持续学习开启后生效。

自动清理范围

保存样本和每日迭代后自动清理本机学习日志；只处理本项目 voice-feedback 目录，不清理 Codex 原始语音历史。

单日样本上限

同一天样本过多时，只保留最新记录，避免某一天的长文本把本地日志撑大。

访问与启动

设置校准中心的固定访问地址，以及启动 Codex 时是否自动打开语音输入校准功能。

固定配置入口

开启后，校准中心使用固定本地地址，方便收藏、脚本打开或从 Codex 内置浏览器访问。

配置网页地址

当前配置网页的访问地址。该地址由本地服务端口决定，保存设置时会自动校正。

随 Codex 启动

开启后，表示希望启动 Codex 时自动启动本地校准服务并打开固定配置网页。该选项仅保存偏好；真正注册启动任务前仍需用户确认。

主动校准

该功能用于手动提供语音输入样本。你确认准备发送给 Codex 的文本会作为该样本的标准答案，用于后续候选规则生成。

自动应用模式

开启后，本页会持续读取新的 Codex 语音历史；发现新语音后自动整理，并尝试直接替换回 Codex 输入框。
